Tables

The tag in HTML is used to define tables, which are used to format and display tabular data.
• tr tag: Used to display table row.
• td tag: Used to display table data.
• th tag: Used in place of table data for displaying table header class.
We can define as many table rows as we want. To add a caption to the table, we use caption tag inside table.
• thead tag: Used to wrap table head (caption & tr with th)
• tbody tag: Used to wrap the table body
